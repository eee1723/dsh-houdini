# 建模方法与细节预算

适用：SOP建模的方法选择、分件、硬表面细化和重复细节。不把这套层次强加给简单编辑、
模拟数据准备或明确要求的原生/NURBS资产。单节点的精确参数、默认值和版本来源读node_info
操作卡；这里仅维护组合方法。先读与当前模块相关的小节，不扫描全部节点。

## 1. 从表示和构造选方法

以人工接手和整体效率选实现：比较构建、cook、局部修改与验证成本，按需混合原生SOP和VEX。
节点数、代码行数或生成token少不证明效率高；用户应能从命名、接线、关键控制和中间输出理解构造，
并能替换资产或修改某一阶段。未知节点行为先查当前操作卡，不凭接口不熟就改写算法。

**重复资产：源资产 → 布局/变体模板 → Copy to Points → 后处理。** 源资产单独建模或引入，
明确局部原点、轴向、单位和输出；位置、朝向、缩放、稳定id与随机种子在模板侧维护。
多种源资产保留独立源分支和明确的变体选择。禁止在VEX循环里逐份重建同一资产的点面来代替Copy；
VEX可构造单个源资产或模板属性，重复实例由Copy生成。重复的是可替换的资产/构件，单个网格的
顶点、连续表面的采样或一次局部属性计算不是资产副本，不强塞Copy。当前任务另有明确实现要求时按用户要求。

**VEX按功能拆分。** 将布局采样、变体/朝向属性、局部形变、分组/材质标记等独立职责放在各自节点，
每个节点说明输入属性及class、处理目的和输出，沿数据流传递中间结果，共享控制保留单一来源。
需要分别调试、复用、替换或观察的阶段应分开；紧密耦合的一次算法保留在同一节点，不机械按行数拆分，
也不把每条赋值都做成节点。简单单功能Wrangle无需额外层次；整个建筑/装配包含多个职责时不能用一个
带参数的大Wrangle代替构造分解。

| 当前意图 | 起点与组合 | 构建前的关键选择 | 模块checkpoint / 不适用边界 |
|---|---|---|---|
| 沿路径的杆、管、带 | 中心线 → 按曲率分配采样 → 截面/方向 → Sweep | 截面来源、局部frame、开闭端；有壁厚的管不同于实心截面 | 实际截面、端边界、转弯处压缩/扭转；不是任意曲面造型通法 |
| 轴对称部件 | 径向/轴向轮廓 → Revolve | 旋转轴、轮廓方向、两端如何连接轴或保持开放 | 半径与轴向尺寸、边界/朝向；不拿周向closed代替端封闭 |
| 板、壳、开孔面板 | 平面轮廓 → 局部Inset/Extrude → 孔槽 → 定向倒角 | 薄片厚化还是已有实体面挤出；保留生成的面/边组 | 壁厚、内外面、孔位置；开放板面是合法输出，不自动实体化 |
| 切除或融合体 | 简单可靠的实体/切割面 → Boolean → 检查接缝 | 各输入Solid/Surface和运算意图 | 实际输出拓扑/朝向/小面与连接；Merge非Boolean，Fuse也非实体并集 |
| 平滑设计曲面 | 低密度控制笼 → 支撑结构/crease → Subdivide | 哪些曲率连续、哪些边应保持；交付拓扑要求 | 轮廓收缩、折痕和高光；细分不会自动设计孔槽、壁厚或支撑结构 |
| 有机融合 | 允许体素近似时才用VDB → 重建表面 | 体素尺寸与最小需保留结构，后续属性/UV恢复 | 薄缝/尖角保留；精密接缝和规定拓扑通常不走此路线 |
| 重复构件 | 独立可替换源资产 → 带身份/局部方向模板 → Copy to Points | 源资产原点/轴向/单位、变体选择、数量/间距和packed/展开交付 | 单件与复制后身份/组传播；查模板唯一性及源替换效果，不靠整体bbox判断无重叠 |

静态不变的平面无需为“高精度”均匀加密；曲线/圆弧的分段数应由轮廓误差或目标观察尺度决定。
参数化Primitive也属于Houdini primitive，不意味着它包含可编辑的多边形面；不要只看primitive count。
VEX适合共享求解、驱动曲线/模板点及原生节点不能自然表达的局部算法；可直接生成网格，但须承担截面、
封口、朝向、UV和可编辑性验证，不能因代码更熟悉就默认重写Sweep/复制/Boolean。原生节点失败先在一个
小原型查输入表示、菜单及选择；替换方法仍须满足原合同，穿插后倒角不等于融合后的连接缝。
纯控制生成点用detail(foreach除外)的Wrangle：`addpoint`一次生成全部实例点；point class的Wrangle
按输入点逐点执行，空输入即零执行，不会凭空生点。VEX里读共享控制用字符串拼绝对路径
（`chf('/obj/rig/CTRL_CART/wheelbase')` 或 `chf(CTRL+'/wheelbase')`），相对路径解析失败可能静默为0；
写后必须cook回读实测点值，不只看snippet无语法错。

## 2. 选择先于倒角与局部操作

优先复用构造节点生成的front/back/side/边界组，必要时与部件身份、位置、方向、夹角条件组合。
Group Create可按几何条件生成组；组的class要与消费者匹配。改变上游拓扑后重新生成并回读组，
不要长期保存某次观察到的边号。一个命名组存在但为空，不算选中了目标。

硬表面圆角通常先排除细分曲面的浅夹角边；角度阈值不是零件语义，不同级别的圆角分组执行。
窄槽、薄壁、拐角密集处按局部间距限制宽度。全部边、点倒角、开放轮廓的圆角也可能是用户意图，
不能因为常用路线是硬边筛选就禁止这些情况。

最小路径：明确目标边 → 建组/角度策略 → 读PolyBevel操作卡 → 小宽度构建 → 查真实边与角部 →
必要时提高截面分段。失败先区分选错、宽度冲突、输入非流形/方向不一致，不反复增加divisions。
checkpoint是选择范围、局部轮廓和输出拓扑；cook成功不能保证无自交。Normal调整着色法线，
不替代修正多边形绕序；二者不能混为“修法线”。

## 3. 一个模块分层细化

先确定交付距离/分辨率、几何用途和显著细节；无参考时把构造选择标为设计假设，不冒充工程认证。
预算用该模块的面数、cook时间、最大细化级别和可见贡献约束，不用固定全项目面数指标。

1. **主形体**：代理体/主要截面/接口。先集成查比例与位置，再投入细节。
2. **构造细节**：分件、厚度、安装座、孔槽、筋。尺寸引用共享控制与接口；改主尺寸仍需成立。
3. **边缘层次**：主要轮廓圆角与微小边缘分组控制，不让所有边同宽。检查整体和局部高光。
4. **重复细节**：先完成可替换的源单元，再按第1节的Copy结构复制；细化源资产时复用已有布局、稳定身份与种子。
5. **微表面**：不影响轮廓/接触的细纹可按用途放材质、法线或位移；显著视差/投影/轮廓需几何。
   制造/测量交付不能用贴图替代实际要求的几何；渲染位移仍需对应的细分与包络检查。

在高成本分支前保留简模/精模选择，主控制与接口不因选择模式漂移。细节attach到语义表面/局部frame，
不要维护另一套独立世界坐标常量。精模完成后集成到实际OUT，检查必需分支而非只查独立模块。
代表性调参同时检查细节响应和应保持的壁厚/接口/数量；没有适用测量就写未验证。

## 4. 停止与验收

主比例或接口失败先回退到骨架，不用更多细节掩盖。两次同边界失败用最小单变量诊断或换方法。
整体图回答比例/分件，局部图回答轮廓/边缘/细节；没有成功semantic inspection则视觉未验证。
最后一次相关修改后刷新受影响检查，不能沿用细化前的闭合/接口结论。面数增长不是验收结果。

重复资产交付检查源入口与模板数据独立；用一个遵守相同原点/轴向/单位合同的不同源形状做替换测试，
确认实际Copy输出随源变化，模板数量/id/位置/朝向/变体规则保持，随后恢复源接线并复验受影响关系。
源尺寸变化可能需要预先声明的适配，不能把物体必然不相交当作Copy保证。VEX拆分按中间输出能否独立
观察与局部修改验收；有spare参数、能cook或拆成更多节点本身均不证明人工易接手。
