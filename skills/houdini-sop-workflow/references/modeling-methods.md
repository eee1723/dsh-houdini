# 建模方法与细节预算

适用：SOP建模的方法选择、分件、硬表面细化和重复细节。不把这套层次强加给简单编辑、
模拟数据准备或明确要求的原生/NURBS资产。单节点的精确参数、默认值和版本来源读node_info
操作卡；这里仅维护组合方法。先读与当前模块相关的小节，不扫描全部节点。

## 1. 从表示和构造选方法

从用户要控制的形态和预期修改选择输入表示，再比较构建、cook、修改与验证的总成本。
尺寸适合参数，轮廓适合截面，走向适合路径，重复件适合独立源与布局；已有网格、体积或算法也可以是输入。
同一产品的不同部分可以采用不同方法，装配通过共享尺寸、接合轮廓或局部坐标连接；无需整件选择同一种生成路线。
保留会被继续修改的入口与中间输出，避免多个分支重复维护同一份几何规则。节点数、代码行数与语言不评价质量。
普通可编辑建模按以下条件选择，不要求对每个节点写选型说明：

| 条件 | 默认选择 | 需要保留的能力 |
|---|---|---|
| 标准成形、组合、重复或局部后处理 | 组合原生SOP，批量创建相关节点 | 对应的路径、截面、源部件和工序可独立修改 |
| 布局、方向、身份、属性计算或定制数学规律 | 职责明确的VEX，再接合适的成形节点 | 输入/输出属性明确，共享规则只有一处 |
| 紧密耦合的自定义几何算法、特殊库，或已测得的计算瓶颈 | 合适的VEX/Python算法或混合网络 | 所需编辑控制、中间观察与最终输出；优化前后比较同样结果 |
| 维护已有工程，或用户指定代码/节点方式 | 保留有效表示，按要求局部修改 | 避免仅为符合默认偏好重建工程 |

“原生节点优先”不要求每个数学表达式都换成节点。反过来，VEX生成不可直接编辑的轮廓后接一个Revolve，
也不自动等于可编辑轮廓：用户要手工改截面时，应提供可操作的曲线或轮廓控制。性能比较使用相同精度、
几何与控制状态，区分首次生成、改参后计算和人工编辑成本；少节点或短代码不能单独证明更高效。
行为不确定时读当前节点卡或缩小原型，接口误用不证明原生方法不适合。

**重复资产：源资产 → 布局/变体模板 → Copy to Points → 后处理。** 源资产单独建模或引入，
明确局部原点、轴向、单位和输出；位置、朝向、缩放、稳定id与随机种子在模板侧维护。
多种源资产可保留独立源分支和明确的变体选择。Copy便于替换源资产并独立调整布局；
VEX可构造源资产、模板属性，也可在连续构造或性能需要时直接生成重复几何。
选择时考虑源替换、逐件编辑、属性传播和计算成本；单个网格的顶点或连续表面采样无需套成Copy。

**VEX的职责与数据流。** 代码边界由调试、复用、替换和观察需要决定。可独立修改的布局、
形变或材质标记适合各自入口；紧密耦合的一次算法可保留在一个节点，不机械按行数或每条赋值拆分。
节点说明输入属性及class、处理目的和输出，沿数据流传递中间结果，共享控制保留单一来源。

**Python SOP适合需要Python库或自定义几何算法的构造。** 与原生SOP/VEX比较实际cook成本、编辑方式和可观察性，按任务选择；代码长度或语言本身不决定质量。可以在普通Python中验证纯数学，再尽早在Houdini检查真实成形与连接。大型生成器应暴露有用控制、几何分组和可检查输出；需要分别修改的源、运动、重复和汇总适合保留独立分支。用户要求脚本生成器时围绕该交付形式设计。原生动词的参数问题先查实际合同，换方法仍须满足用户目标与执行边界。

| 目标与编辑入口 | 可用组合 | 需要明确的输入关系 | 能区分效果的观察 |
|---|---|---|---|
| 对称构件，修改一侧或对称面 | 单侧源 → Mirror；接缝按意图合并 | 复制完整源还是先裁半边；对称面位置/方向、是否保留两半与焊缝 | 改源后对应点/部件位置；接缝重复覆盖、边界和法线；整体bbox对称不能证明局部对应 |
| 重复构件，替换一份源或调整布局 | 独立源 → 带身份/方向的模板 → Copy to Points | 源原点、轴向、单位；模板数量/朝向/变体；实例与展开输出 | 换源时布局保持，改数量/间距时单件形态保持；源变大不保证无碰撞 |
| 沿路径的杆、管、带，修改走向或截面 | 中心线与截面 → Sweep | 路径与截面职责不同；开放/闭合、切向、截面朝向与端盖 | 源路径、成形截面、扭转、端边界；不要把实体边倒角与曲线扫掠混为一种操作 |
| 轴对称部件，修改径向/轴向轮廓 | 截面 → Revolve | 旋转轴、轮廓方向、与轴连接或保持开放；螺旋推进需额外构造依据 | 轮廓变化是否传到表面、边界/绕序；周向闭合不证明两端封闭 |
| 板、壳、开孔面板，改轮廓/厚度/局部边缘 | 轮廓或表面 → PolyExtrude → 孔槽/倒角 | 薄片厚化与已有实体挤出不同；保留可选的前/后/侧面 | 截面实际厚度、内面与局部间隙；平面厚化示例不保证任意曲面无自交 |
| 多截面过渡形体，局部改一个截面 | 有序截面 → Skin；已有边界间接合另按现场选择Bridge类操作 | 截面顺序、方向、接缝位置、连接方式；开放面与闭合体意图 | 截面变化和局部曲率/扭转；输出非空不证明截面正确对应或自动封口 |
| 已有形体沿曲线路径变化，保留源细节 | 源形体与目标曲线 → Path Deform | 源纵向轴、捕获范围、路径方向/起点、长度适配与截面朝向 | 路径改变后的标记点、截面与局部伸缩；这与从路径新建管面不同 |
| 弯曲/扭转/渐缩，改变幅度或作用区 | 足够采样的源 → Bend或合适的局部形变 | 作用轴、原点、捕获区、模式与输入/参考形态 | 有意选中的点如何移动，区外行为和表面形态；写角度成功不证明几何处在作用区 |
| 切除或融合体 | 先验源表示 → 单个切割/融合原型 → Boolean → 接缝与效果检查 | 分别声明Solid/Surface、输入顺序和运算意图 | 查源边界/朝向和实际切除或融合，见下节；Merge非Boolean，Fuse非实体并集 |
| 需贴合的分层外壳 | 共享接合轮廓/截面 → 各自厚度/偏移 → 壳、边框、盖面 | 共同轮廓、壁厚/间隙、各层连接方向 | 主尺寸扰动后查真实接合面；独立离缝造型或现成外部资产不强求同一生成器 |
| 平滑设计曲面 | 低密度控制笼 → 支撑结构/crease → Subdivide | 哪些曲率连续、哪些边应保持；交付拓扑要求 | 轮廓收缩、折痕和高光；细分不会自动设计孔槽、壁厚或支撑结构 |
| 有机融合 | 允许体素近似时才用VDB → 重建表面 | 体素尺寸与最小需保留结构，后续属性/UV恢复 | 薄缝/尖角保留；精密接缝和规定拓扑通常不走此路线 |

静态不变的平面无需为“高精度”均匀加密；曲线/圆弧的分段数应由轮廓误差或目标观察尺度决定。
线圈接自由线头时，末端曲线应沿线圈末段切线离开，再平顺到目标端点；不能只在
位置上接住，切向突变仍会形成折角。直接VEX逐环生成管面时，用固定参考轴在
切向接近阈值处切换会让截面突然翻转；产品电缆优先让VEX只输出中心线，
由Sweep计算连续截面。H21/H22的开口中心线→内建圆管→单面端盖正反例见
仓库源码测试`tools/tests/dsh-node-knowledge.test.py`。
参数化Primitive也属于Houdini primitive，不意味着它包含可编辑的多边形面；不要只看primitive count。
用户需要编辑路径、截面或源形体时，VEX生成这些中间几何、原生SOP负责后续成形是一种可选组合；
直接生成网格同样可以满足任务。两种路线都需要按所声称的性质核对真实输出，原生节点不会修正错误输入。
原生节点失败先在小原型查输入表示、菜单及选择；替换方法仍须满足原合同，穿插后倒角不等于融合后的连接缝。

### 高风险成形的最小检查

适用：结果依赖输入实体条件、节点模式或相邻件贴合的产品构造。先选当前风险对应的一行，
在单元上完成一次「前提→操作→实际效果」；不要求每个简单编辑跑全表，不把这些检查当成制造认证。

| 风险 | 最小检查与失败转向 |
|---|---|
| 参数写入但模式不使用 | 先读模式与参数适用条件，再作一个有明确预期的单变量扰动并读实际输出。细分看采样/拓扑与轮廓，厚度看截面；未响应先查模式、接线或选择，不继续增大同一无效值。恢复后才扩建。 |
| Boolean源不满足实体前提 | Solid输入先查边界、共享边方向、整壳朝向；旋转/扫掠接缝核对是否真实连接。只有证据显示意外重复接缝才Fuse，朝向错误才Reverse；不对合法Surface或设计间隙盲修。失败先定位源，不能反复切换布尔菜单。 |
| 运算完成但形状相反 | 对声明为Solid的A−B，结果超出A包络且超过量测容差可否定减法效果；包络未超出仍需孔轴/截面或局部图证明切除了目标。融合另查实际连接，不能用减法判据。读取成形节点自身warning，最终Null的无warning不替代上游证据。 |
| 相邻层只有视觉靠近 | 先共享接合轮廓与局部frame，各层从它派生厚度/允许间隙；改变一个主尺寸，量测最终接合表面。独立外部资产保留各自构造，以明确接口适配并验实际关系，不为贴合强制Fuse。 |

闭合、相邻面方向一致、整壳朝外是三个问题。Normal只改变着色；有向体积符号依赖约定，
须结合已知外表面方向及检查方法的适用范围，不从一个任意正负号推断所有壳朝向。
图像暴露凸起/开缝等反例后，先在原型定位源或依赖，再修复并重看；提高分段数不修接合设计。

### 逻辑模块与容器选择

模块用于解释输入、处理和输出；容器由复用、替换与接手需要决定。同一SOP网络中的平铺分支适合快速观察，源、局部处理、放置/复制与组装沿数据流相邻。重复组件尽量共享构造来源；稳定的`OUT_<MODULE>`或`OUT_ASSET`可作为消费者接口，但不要求每条短链添加Null。Network Box改善可读性，不代替真实端口。

独立复用、导出、替换、少量稳定公共端口或用户明确要求层级时可使用普通SOP Subnet，也可在构建时直接选用。整理已有网络时核对输入、消费者和参数依赖，按实际风险选择原地调整或候选分支；发布原生Output并复验消费者。强耦合连续曲面、跨模块Boolean、接口频繁变化或短链通常适合同层。HDA用于用户需要共享类型或安装分发的交付。

私有细节留在组件；跨组件连接件归最低共同装配层。模块内部不保留OBJ/工作区绝对路径，同层优先相对兄弟引用，Subnet只经公共输入/参数连接外部。全局自由量只有一个维护源，组件公开局部量仅在改变外包络/接口时提升给父级。
纯控制生成点用detail(foreach除外)的Wrangle：`addpoint`一次生成全部实例点；point class的Wrangle
按输入点逐点执行，空输入即零执行，不会凭空生点。同层读共享控制优先相对路径，
例如`chf('../CTRL/wheelbase')`；跨Subnet经公开输入/参数传递，不把当前OBJ绝对路径写进内部。
相对路径也可能因移动节点而失效，写后须cook回读实测点值，不只看snippet无语法错。

## 2. 选择先于倒角与局部操作

优先复用构造节点生成的front/back/side/边界组，必要时与部件身份、位置、方向、夹角条件组合。
Group Create可按几何条件生成组；组的class要与消费者匹配。改变上游拓扑后重新生成并回读组，
不要长期保存某次观察到的边号。一个命名组存在但为空，不算选中了目标。

硬表面圆角通常先排除细分曲面的浅夹角边；角度阈值不是零件语义，不同级别的圆角分组执行。
窄槽、薄壁、拐角密集处按局部间距限制宽度。全部边、点倒角、开放轮廓的圆角也可能是用户意图，
不能因为常用路线是硬边筛选就禁止这些情况。

最小路径：明确目标边 → 建组/角度策略 → 读PolyBevel操作卡 → 小宽度构建 → 查真实边与角部 →
必要时提高截面分段。失败先区分选错、宽度冲突、输入非流形/方向不一致，不反复增加divisions。
checkpoint是选择范围、局部轮廓和输出拓扑；cook成功不能保证无自交。Normal调整着色法线，
不替代修正多边形绕序；二者不能混为“修法线”。

## 3. 一个模块分层细化

先确定交付距离/分辨率、几何用途和显著细节；无参考时把构造选择标为设计假设，不冒充工程认证。
预算用该模块的面数、cook时间、最大细化级别和可见贡献约束，不用固定全项目面数指标。

从模块用途选择有意义的细节：操作/握持需要什么，零件如何定位和紧固，薄壁或安装处如何支撑，
孔槽与边缘怎样形成近景层次。复杂设计可在现有计划中记下用途、依附关系、控制与观察方法，
不需要另填固定字段；用实际局部原型判断方案。

| 设计问题 | 可选择的结构 | 必须一起考虑 |
|---|---|---|
| 用户怎样操作 | 握持轮廓、防滑纹、刻度、调节空间 | 尺度、运动避让及实际可见性 |
| 零件怎样安装 | 孔/沉孔、螺钉座、定位台阶、配合槽 | 连接双方共享位置，孔/杆/座的实际配合 |
| 局部怎样支撑 | 带厚度的肋板、根部过渡、支撑座 | 从真实承接面生成，检查整个脚面与邻件 |
| 形体如何制造和拆分 | 壁厚、分件缝、孔口处理、局部避让 | 不同部分的构造一致，不能把穿插说成接合 |
| 近景需要哪些层次 | 主轮廓圆角、中尺度边、微倒角和纹理 | 按观察距离和局部间距选尺寸，不全边同宽 |

只选择与对象用途一致的项，不按固定数量塞满细节。用户未规定的设计可由作者选择并记录假设，
不把自行选择的孔距/紧固件规格冒充外部事实。毫米输入先统一转米；几何细节要在最终输出存在，
不能以文字说明、节点名称或材质颜色代替。已有共享模板按procedural-recipes选择，局部表面不适配时回到原型。

以下层次帮助选择细节的表示和观察范围，可按任务交替推进：

- **主形体**：代理体、主要截面或接口，用于观察比例与位置。
- **构造细节**：分件、厚度、安装座、孔槽、筋。尺寸引用共享控制与接口；改主尺寸仍需成立。
- **边缘层次**：主要轮廓圆角与微小边缘可分组控制，检查整体和局部高光。
- **重复细节**：可替换的源单元配合第1节的Copy结构；细化源资产时复用布局、稳定身份与种子。
- **微表面**：不影响轮廓/接触的细纹可按用途放材质、法线或位移；显著视差/投影/轮廓需几何。制造/测量交付不能用贴图替代实际要求的几何；渲染位移仍需对应的细分与包络检查。

### 表面表示与外观制作

从用户要编辑的量与最终观察距离选载体，不把所有表面变化都增加到网格上：

| 需要表达的性质 | 合适的载体与边界 |
|---|---|
| 轮廓、实体厚度、接合、真实孔槽 | 可编辑几何；颜色或贴图不能代替结构 |
| 布局权重、构造mask、部件调试色 | 属性或Cd；数值分辨率受承载点/面与插值影响 |
| 连续漆面分界、logo、照片贴花、微表面 | 材质直接采样连续遮罩/纹理；需要图像校正、组合或制作时加载houdini-cop-workflow |
| 恒定颜色、roughness等材质值 | 直接设置材质参数；简单解析式遮罩也可在shader内计算，不强制烘图 |

稳定部件/材质身份用明确的组或类别属性维护，不从显示用RGB阈值反推。将连续颜色或alpha先采到点、
再按每面首点或平均阈值分配材料/删面，会把边界量化到网格，增加采样密度也增加维护和计算成本。
真正需要切割网格时按几何目标构造；仅涂装/透明度应由材质读取对应UV与过滤后的图像，不把Cd预览当最终贴图。
需看实际材质时按名加载houdini-solaris-karma-workflow；构造细节和外观可按当前疑点交替推进。

在高成本分支前保留简模/精模选择，主控制与接口不因选择模式漂移。细节attach到语义表面/局部frame，
不要维护另一套独立世界坐标常量。精模完成后集成到实际OUT，检查必需分支而非只查独立模块。
代表性调参同时检查细节响应和应保持的壁厚/接口/数量；没有适用测量就写未验证。

## 4. 停止与验收

主比例或接口有误时，回到影响它的构造定位原因；重复失败可用最小单变量诊断或换方法。
整体图回答比例/分件，局部图回答轮廓/边缘/细节；没有成功semantic inspection则视觉未验证。
最后一次相关修改后刷新受影响检查，不能沿用细化前的闭合/接口结论。面数增长不是验收结果。

观察应能区分具体原因，再选择修改；已有正确信息不必重查整个网络。以下是诊断例子，不是每件资产的固定检查表：

| 症状 | 能区分原因的观察 | 修改方向 |
|---|---|---|
| 统计存在的部件在图中看不清 | 隔离该部件与邻接面，检查局部截面、深度与实际连接位置 | 区分被包埋、遮挡和轮廓层次不足，修改相关截面或放置关系 |
| 细杆出现宽片、尖刺或不正常接头 | 先看成管前的线段、共享端点与急转弯，再看局部截面 | 按独立杆件或连续管路的实际意图处理连接，不先靠加面或材质掩盖 |
| 数量、尺寸能变但形体关系失效 | 在改变的状态检查实际成员、厚度、间距与承接面 | 调整共享参数关系；件数变化和bbox变化不能替代这些观察 |
| 模式正确与否不确定、输出为空 | 对照当前解析类型的菜单token与实际输入元素；用一个可观察单元验证 | 修正模式/输入后再判断节点能力，不从错误模式推断平台不支持 |

`render_view`的命名方向是固定世界空间预览，`side/front`带轻微仰角，不自动识别对象正面。
检查沿轴轮廓时使用对象实际世界轴对应的方向向量；正交投影本身不保证沿轴。疑点尚未解释时，
用聚焦观察或局部修改继续判断，最终表述保留实际未覆盖的范围。

重复资产交付先回读模板点的实际位置、首尾跨度与相邻间距，再核对复制后各件中心；Line SOP 的 `dist` 是整条线长度，不能把它直接当相邻点距。检查源入口与模板数据独立；用一个遵守相同原点/轴向/单位合同的不同源形状做替换测试，
确认实际Copy输出随源变化，模板数量/id/位置/朝向/变体规则保持，随后恢复源接线并复验受影响关系。
源尺寸变化可能需要预先声明的适配，不能把物体必然不相交当作Copy保证。VEX拆分按中间输出能否独立
观察与局部修改验收；有spare参数、能cook或拆成更多节点本身均不证明人工易接手。
