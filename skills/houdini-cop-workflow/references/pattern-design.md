# 程序图案与材质图层设计

适用：需要在COP制作可编辑图案、遮罩或多通道表面数据；不是固定材质样例库。表面表示、参考分析和来源选择由houdini-surface-workflow负责。

## 由结构关系选择算子

先描述图案的主要单元、分布、方向、尺度和层叠关系，再发现能表达这些关系的当前COP节点。不要将Substance节点名机械替换成猜测的Houdini节点。

设置参数时同时核对所属模式和启用条件。node_info/list_parms的conditionals是参数自身的原生界面条件，隐藏/禁用不等于禁止预设值，也不证明该值参与当前计算。按钮条按menu_kind与set_value操作，不能把图标token或选项序号当成开关值。Fractal Noise的逐轴尺度由Per-Component Controls启用，percomp另指颜色通道噪声；精确规则由节点卡维护。沿声明的意图改变一项参数并观察输出，数值回读成功不代替效果。

| 图案关系 | 可组合的思路 | 核对对象 |
|---|---|---|
| 重复单元 | 单元形状→重复／散布→受控变化 | 单元间距、方向、边界、种子稳定性 |
| 连续条带／流向 | 坐标或坡度→周期／噪声→定向变换 | 两维采样、方向和相位；不是只增加噪声频率 |
| 材质覆盖与分层 | 基底→共享覆盖mask→颜色／粗糙度等混合 | 同一mask对应同一物理区域；只改变需要改变的通道 |
| 表面起伏 | 主高度形态→局部加工→微细节→必要法线 | 高度零点与单位、幅度、频率及法线方向 |
| 磨损／积尘 | 有依据的位置／接触／曲率等驱动→局部mask→细节 | 几何驱动需真实导入／烘焙；噪声不证明接触或边缘磨损 |

从大尺度结构到中尺度变化、微细节逐步观察；不是所有材料都必须走三层。高度主导的材料可先高度，平面印刷以颜色／mask为主，金属拉丝可能以方向与粗糙度为主，不强制“高度先行”。

## 复杂图案的组合

将复杂度放在能解释外观的结构关系上：先确定坐标与单元/区域，再用分布、变形、层叠和局部变化组合。每个关键mask可独立观察并被需要的通道共享；不要求拆成固定节点数量。

| 结构需求 | 可编辑组织方式 |
|---|---|
| 重复纹样、格栅、织纹 | 有限周期单元→周期分布→边界连续的扰动→局部细节；单元数量、实际周期和像素分辨率分别控制 |
| 多色印刷、分区涂层 | 图案/区域mask→底色混合→该区域的粗糙度；平面印刷不必同时制造起伏 |
| 颗粒、石片、嵌件等多尺度材料 | 主单元形状与ID→尺寸/分布变化→细颗粒层→共享边界及各通道响应 |
| 绘画、复杂自然外观与规则区域组合 | 文件素材→局部校正→确定性mask/布局→必要表面通道，生成素材沿表面skill |

优先发现当前版本的原生算子并组合；一小段数学关系用Wrangle更清楚时可以使用。保留能解释与调整的阶段，不把整个材质藏进一段巨大程序，也不为了节点数量把简单公式拆碎。COP的Image/Texture/Pixel坐标空间、图像长宽比和采样边界应与组合意图相符；不同大小的输入不一定自动共享同一物理尺度。

## 共用结构，按角色输出

从少量共享的结构mask、ID或高度派生相关通道，保持空间对齐；不分别随机生成颜色、法线和粗糙度。
通道相关性按材料含义决定：深色不必凹陷，白色不必粗糙，涂层和基底的金属度不能简单按亮度猜。
颜色层与mask可用相应Blend操作；normal是方向向量，组合多个法线时使用支持该语义的Combine Normals，而非普通颜色混合。高度可先合成再生成法线，幅度和数据编码另行核对。
用局部mask限制变化，避免整物均匀加噪声。底色避免直接乘入观察灯光或AO阴影；特殊风格化意图需明确。
先保留少量有意义的控制：结构尺度/方向/数量、变化种子、覆盖比例、色调、粗糙度或起伏强度。建立依赖与可观察输出后再加控制，不把每个底层参数都暴露给用户。

## 分辨率、复用与迭代

- 重复结构复用子网或既有源；相同图层供多个通道和多个部件消费。网络分组与交接沿houdini-network-handoff。
- 低分辨率先判断结构和坐标；最终分辨率重验细线、滤波、法线与接缝。只需标量的数据保持单通道，精度按量程选择。
- 将图案单元、物理重复尺度与图像分辨率分开设计。可平铺的微结构先制作覆盖若干周期的连续单元，通过UV/采样控制表面上的密度；大尺度变化可另用低频层。需要独有定位、非周期变化或烘焙时再评估整面贴图，不因可见重复就同时扩大画布与单元数量。
- 无需改变结构的末端调色／强度调整尽量靠近相应输出，减少重算；真正影响结构的控制保留正确上游依赖，不能为了缓存改变语义。
- 每次修改明确当前差异：位置、比例、边缘、层次或某个通道响应。观察中间图层和实际承载表面，再决定下一步，不只看图像均值或反复增加节点。方向纹理需要看主方向与频率；U/V梯度可作为已声明方向的辅助量测，需考虑像素尺度和长宽比，不能把方差非零当成木纹、拉丝或织纹成立。
- 需要平铺时，使用周期性坐标／生成和兼容边界的变换；单纯把采样设成Wrap不保证接缝消失。最终U/V边界及多次铺贴分别检查。

细化前保留一个效果与耗时已知的基线。分辨率、图案数量/频率、UV覆盖、法线幅度和采样过滤是不同变量；针对当前可见问题逐项比较，避免同时修改后无法判断原因。图案模糊、接缝、规则重复和法线噪点不必有相同解法。采用实际cook/预览耗时，不用像素数或单元数相乘冒充节点复杂度，也不设置通用分辨率/数量上限。

预期较长的评估可用现有houdini_job_*提交与收集，任务仍经过同一个Houdini主线程队列，并不会使计算本身更快。通信超时后用原request_ref查回状态；排队中的界面/场景查询不能独立诊断该计算。先确认旧请求结束及现场状态，再改变精度或重试。

图层/端口发现、控制恢复、导出读回沿现有COP资料，不新增图案专用执行系统。简单的现成图像输入不需要重建为程序图。

## 外部依据与迁移范围

- [SideFX：面向Substance Designer用户的Copernicus](https://www.sidefx.com/docs/houdini/copernicus/substance_designer.html)：概念对照，不保证两个软件节点一一等价。
- [SideFX：Blend](https://www.sidefx.com/docs/houdini/nodes/cop/blend.html)与[Spaces](https://www.sidefx.com/docs/houdini/copernicus/spaces.html)：图层混合、法线组合的区别与采样坐标。
- [Adobe：Designer入门课程](https://www.adobe.com/learn/substance-3d-designer/web/getting-started-with-substance-3d-designer)：展示结构、图层、通道及可调子图的组织；这里提取方法，不复制其具体材质配方。
- [Adobe：性能指导](https://experienceleague.adobe.com/en/docs/substance-3d-designer/using/best-practices/performance-optimization-guidelines)：分辨率、数据体积与末端调整的依赖成本。COP性能仍测本机cook，不能照搬Substance缓存策略。
- [DCC-MCP的Designer适配说明](https://dcc-mcp.github.io/control/substance-3d-designer)：发现真实工具／参数、执行可检查变化、核对输出。它是第三方适配项目，不是Adobe质量保证，也不是本插件的新依赖。
- [VLMaterial](https://arxiv.org/abs/2501.18623)：图像到可编辑材质图的研究；据此保留结构和实际观察，不推导提示词即可保证复现，不引入专用训练或另一套agent。
