# COP 关系与控制验证

Applies when：多层组合、控制驱动、随机化、版本迁移或参考复现需要证明因果关系。
Do not use when：规格完整的单步编辑只需对应回读；不强迫所有图层做完整统计或所有任务做渲染。
数值机制已有 H21/H22 隔离回归，整体工作流采用仍是候选；不是通用艺术质量评分器。

## 观察合同

在现有任务记录中给核心模块写：输入/输出角色、操作、预期关系、测量范围、容差来源与未测项。
读数据时返回实际节点/输出、通道、类型、尺寸、frame、采样区域与数量、非有限值、范围和必要统计。
保留有界摘要与证据位置，不将完整像素数组反复放入上下文。
未覆盖全图时明确是采样诊断；稀疏异常不能凭抽样均值排除。

当前优先用 exec 中的 `cop_layer_stats(node, output=源输出名或索引)`，直接读 ImageLayer 完整
buffer，输出逐通道统计、U/V 梯度和已列元数据/字节指纹；超 max_pixels 拒绝而不隐式抽样。
预算限制读取量，不限制上游 GPU cook 分配；未知重网络先隔离。Fixed 定点存储目前拒绝，不偷偷转型。
Manual、失败 cook 和非图层拒绝；sticky Cache 新鲜度未验证，不把输出尺寸当缓存已刷新。
SOP `verify_network`/`test_controls` 不覆盖 COP；不要绕回“第一个 Volume”代理。
观察能力缺失则保留 unverified，不把缩略图、显示色或非零数组当等价证据。

## 先校准判据

以组合层为例，明确 A=修改前输出、D=声明增量、B=修改后输出：

- 实际变化测 `B - A`，不是 `D - A`。
- 只有操作确认为纯加法且无夹取/混合/重采样时，才检验 `B - A ≈ D`。
- 用已知常量或零增量校验公式、符号、通道、对齐及归一化分母，再用该量测调资产。
- 差值失败时先检查测量对象和求值新鲜度，不先把强度调小至“通过”。

容差根据浮点精度、编码和目标用途声明；不能遇到失败就放宽阈值。数学一致性不证明损伤等视觉效果充分。

当前 `cop_compare_layers(before, after, expected_delta={'node':增量节点,'output':源输出})` 检查
`(after-before)-expected_delta` 的最大绝对误差；具体签名先 verb_help。
不提供 expected_delta 时只返回差值量测/unverified。不同通道、窗口、空间或帧不静默对齐；
该工具不能替作者决定 A/B/D 的数学角色，也不是前一请求的自动历史快照。

## 驱动→响应→恢复

1. 记录基线参数、表达式/keys、frame、随机 seed、相关缓存状态和实际输出证据。
2. 选择一个有可检验预期的干预，固定其余变量。例如改变坐标只应改变对应采样关系；
   阈值遮罩在固定高度与定义下应有预期包含关系。不要对任意噪声随机化套单调性。
3. 在 exec 修改与求值，比较明确输出；同时看应变与应不变的量，拒绝仅凭 pixel diff>0 宣布通过。
4. 无论检查成功或失败都恢复已快照状态并重新求值；回读参数与输出，确定性范围内检查相同值/指纹，
   非确定性输出采用事先声明的容差。Cache 旧结果可能掩盖恢复失败，不能只测缓存图。
5. 恢复失败立即停止进一步调参，报告当前值、未恢复项与影响。外部文件、脚本、solver 状态、
   OpenCL 非确定性或其他外部副作用不因参数恢复就获得恢复保证；先在隔离场景设计专门验证。

只给已测试控制结论；有控制面板、参数能变、三个控制通过都不证明所有控制通过。

当前 `test_cop_controls` 支持数值标量、显式 output_port 和逐通道 mean/min/max/
mean_abs_change/max_abs_change 的 delta/range；精确 schema 用 verb_help 读取。
每case至少一个非零响应预期，range 同时检查基准与扰动；返回 status/restored 与逐项实际测量。
恢复复用参数/keys/frame机制并核对完整 buffer 和已列元数据；当前采用精确指纹，不能声称已支持
非确定性容差恢复。菜单/tuple/multiparm/callback 与 sticky Cache 拒绝；恢复失败会抛 CheckpointError。

## 平铺与视觉

仅对需要平铺的输出：在最终有效分辨率，分别测 U/V 边界跳变并与对应方向内部梯度比较，
同时查看重复铺贴结果。阈值取决于数据用途和过滤；Wrap 只定义越界采样，不保证内容无缝。
边界像素不必机械相等，且边界均值相近仍可隐藏局部接缝；数值检查需保留范围和反例。

参考复现按用户目标列少量形态/细节/材质特征，在固定取景与说明的照明条件下读图。
显示变换、视口 hillshade、正常数据着色与实际材质效果分开；参数关系测试通过不证明外观达标。
调了上游、分辨率或绑定后，将受影响结论标待复验，最终不引用旧阶段统计。

依据：项目执行证据边界与已审计的单任务失败候选；官方图层空间/显示解释见
[Spaces](https://www.sidefx.com/docs/houdini/copernicus/spaces.html)。
机制覆盖与仍待执行的模型行为见 [验收矩阵](evidence-and-validation.md)。
