# 风格目标与部件来源

## 目标与参考

从用户文字、参考图或现成模型提取会改变造型的特征，例如轮廓比例、材料组合、纹样语言、磨损程度和交付时的观察距离。已有方向清楚就直接做部件；需要比较整体轮廓或协调几种材料时再生成整体概念图。它可以定风格，实际尺寸及隐藏连接由工程决定。

生成部件时，把相应的风格图或可见裁片实际交给图像工具，用同一色板、纹样密度和材料生成部件参考。已有合适的部件图可直接复用。尺寸或孔洞重要时可先用简易代理表达形体，给每张输入标明用途。仅支持单图的建模入口，先把风格与形体合成清楚的对象图。传递参考或迁移工程见[参考迁移方法](../../houdini-task-decomposition/references/reference-transfer.md)。

## 粒度与来源

| 用户需要保留或改变什么 | 合适的来源 |
|---|---|
| 近看要保留铸造、雕刻、风化轮廓和表面 | 选择同风格的现成或生成高模，整件共享；需换外观时按同接口取得变体 |
| 大面积立面、重复边框或立柱影响整体细节 | 可换成带材质的完整原型，或用高模端件配原生可调中段；在与相邻件同框的近景判断 |
| 跨度、开口、可调截面、精确支承随参数连续变化 | Houdini原生构造；规则大面可用平铺或trim纹理，影响剪影的凹凸用真实形体 |
| 只需整体放置的独立物件 | 可直接取得完整模型，并保留位姿、均匀缩放和替换入口 |

部件边界取决于编辑与安装用途。中段重复件、端部封口与跨面盖件可能需要不同的接合面；每个家族内的磨损、纹样或轻微轮廓变化可以共享同一接口。优先取得能试出安装关系的代表件，同时推进规格已定的其他家族。按[尺寸与装配](dimensions-and-assembly.md)把真实源的基准、有效节距和允许变形区交给使用它的构件。

## 生成参考

给成组部件参考图的提示可直接写成一段话，把括号内容换成作品自身的设计：

> 沿用参考建筑的〔材料、色板、造型或纹样〕，绘制一组完整的〔同一安装用途的组件〕。保持〔底面、长宽比、孔洞、拼接方向〕，仅在〔纹样、磨损、局部饰件〕上有微差。相同机位和尺度，中性光照，各件留空隙，完整显示轮廓和必要侧面，去掉地台、文字和投影连片。

数量取决于图上每件的像素和交付距离，尺寸相差太大或功能不同的部件可以分板。对孔洞、方向和比例敏感时先看实际生成的参考图，纠正图片通常比重做高模便宜。多视图输入表达同一个物体的不同角度，变体板上的不同组件各自保留完整视图。[Tripo 多视图](https://www.tripo3d.ai/product-doc/model-generation/multi-view-to-3d)

## 成组变体参考与多组件取得

同一张参考图可以通向不同结果。独立模型可以分别取得，共用图集的集合可以直接拆用；不要求某种服务或固定分件流程。以下是已经选定 Tripo 时的示例，不是其他服务的接口说明。实际可用性、价格和权限以当前配置及对应提供方为准。

| 希望取得的结果 | 选择与代价 |
|---|---|
| 各变体有自己的高模、材质与生成结果 | Tripo Studio 的 Variants 生成成组图，Cutout 分离各件，再用 Batch to 3D 独立生成。已有家族图可从拆图开始。CLI 可用每件裁图作为单图输入，沿提供方批处理；一次批量操作可对应多个收费任务。[官方变体工作流](https://www.tripo3d.ai/blog/tripo-image-gen-update) · [批量生成](https://www.tripo3d.ai/product-doc/model-generation/batch-image-to-3d) |
| 同一图生成集合模型，在Houdini选取其中完整部件 | 保留生成原件，检查可独立取用的对象、完整形体和共享图集。如果需要由图片建模并语义分件，可在支持的入口选择 Smart Segmentation。它返回分件模型，部件数量、分割边界和纹理需看结果。[Smart Segmentation](https://developers.tripo3d.ai/en/docs/mesh-smartsegment) |
| 已经有集合模型 | 优先提取现有对象。一件可以包含多个材质片和不相连的零件，按实物决定哪些应归为同一原型。源已融合时可尝试提供方的现有模型分件；AI补全可能改变接合面与细节。[分件 API](https://developers.tripo3d.ai/en/docs/mesh-segment) · [Studio 分件](https://www.tripo3d.ai/product-doc/module-post-processing/segmentation) |

实际客户端可能只提供其中部分能力。H系列的 `generate_parts` 与同时生成纹理／PBR 有兼容限制。需要保留表面时比较拆图独立生成、现有集合提取和后续纹理处理的总费用与质量。保留得到的GLB和材质，再分别建立各件的局部基准与安装尺寸；共享图集按依赖打包。[H 系列图生模型](https://developers.tripo3d.ai/en/docs/generation-image-to-model/standard) · [资产接入](../../houdini-asset-integration/SKILL.md)

**等待和重试。** 同一批独立来源可交给提供方已有的并发与恢复能力，按当前版本帮助确定用法。保存任务号，云端工作时先做本地布局；需要结果时等待原任务。提交超时或网络中断先查原任务，已下载资产遇到显示问题就修本地消费链。新增收费步骤沿已有授权范围处理。[官方 CLI](https://developers.tripo3d.ai/en/docs/cli)

## 材质家族

在相同光照与观察距离下比较最终实例的纹理尺度、粗糙度、色差、接合处轮廓和图案重复。明显重复的裂纹可用相容变体及稳定的外观种子改善，同时保留拼接方向和安装面。整片表面显得空时，检查是缺形体、缺纹理还是材质接错，再处理对应来源。

尽量保留原资产的UV、法线、贴图和材质索引。原生可调段可以使用平铺或trim材质，在接点与高模一起比较；不同UV的原型各自消费适用的贴图。确需对已有模型重新纹理时，比较新旧网格、UV与材质并保留原型。[Tripo 纹理](https://developers.tripo3d.ai/en/docs/models-texture) · [Houdini 表面方法](../../houdini-surface-workflow/SKILL.md)
