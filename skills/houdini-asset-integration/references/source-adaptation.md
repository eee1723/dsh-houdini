# 套件参考与源接口适配

适用于把外部资产接入已有组件，或以生成资产建立可复用套件。组件边界、规格和接头归属由 [SOP 完整源与布局](../../houdini-sop-workflow/references/modeling-methods.md#完整源组件与布局)维护。根据本次风险选择下面的方法。

## 用同一份设计派生参考

整体参考确定轮廓、材质和细节方向。需要精确互换时，以简化定尺代理确定安装面、实际接边截面、节距与分件位置。对连续图案还要指定跨缝的图案节奏与起止位置。保留检验这些量需要的可比视角和尺度。参考图中的尺寸标注用于沟通，几何校准以代理或已确认的实体接口为准。

逐件生成时，从同一设计和尺度基准派生各件参考。每组多视图描述同一个分件的同一状态，保持轮廓、材质方向和开口对应。在授权和成本允许时，先取最常复用或接口风险最高的一件，用真实网格试装再决定余件。要求接边或外观高度一致时，比对共用母体拆分、在合格源上派生局部变体和独立生成的成本。共用母体可继承整体形体与材质，拆件后仍要检查重复件首尾是否连续。提交视图、登录、费用和生成沿提供方技能与当前接口。

## 判断源是否适合接入

- 保留原资产。先做一次单位换算或等比标定，再旋转、平移对齐功能基准。按同一变换比较所有接口、主要比例和必要净空。距离错在单一坐标基准时修适配。各接口无法同时对齐、主体比例不合或开口缺失时，先把原件标为候选，比较同源派生、替换或经授权的重新获取。符合要求才发布正式源。后续固定件的放置沿用 [规格与变换分工](../../houdini-sop-workflow/references/modeling-methods.md#完整源组件与布局)。
- 仅在明确允许且成本可控时修整局部余料、预留接边或修复已证实的导入缺陷。按实际改动区分坐标适配与源形变。整体改形、重做接边拓扑和逐件材质重建属于额外制作，按任务授权、质量收益和后续换源成本单独判断。验证问题来自源件后，避免继续用复杂适配掩盖超差。
- 严格同色时，用同光照和颜色管理对照相邻件。先看源的对应材质区域，再看实际绑定/显示；只在证据指向该层时修正。适合共享的材质沿用一个着色入口或共用贴图基准。不同 UV 的独立贴图可分别保留，必要时只做可复用的颜色校准，方法沿 [外部资产材质接入](../../houdini-surface-workflow/references/sop-preview-and-uv.md#外部资产材质接入)。
- 用适配后的真实源试装代表接头，再扩充分布。按 [实际模块质量合同](../../houdini-sop-workflow/references/module-quality-contracts.md)核对最终实体关系。端面距离通过只覆盖该项测量，沿接边的错台与外观另用近景或剖面判断。有意开口在要求的位置与范围内检查可能遮挡它的实际层。探针可按真实实例和局部范围缩小预算，保留未覆盖的范围。
