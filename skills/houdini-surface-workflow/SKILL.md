# Houdini Surface Workflow

## 目标与默认入口

按最终观察距离和后续编辑选择表示，再约定构造与分工。结构、图案和材质响应分别可编辑；原生SOP、COP和材质均可承担交付。依赖能否随工程携带与是否使用图案分开判断，内嵌COP也可产生贴图。
新建SOP资产默认用 **COP Preview Material SOP** 统一承载表面，接入实际几何输出。颜色从稳定的COP输出开始：简单表面用小分辨率常量图层，复杂表面逐步接入程序图案或文件素材，预览入口保持一致。
纯色无需UV或外部图片文件；已有常量材质可以保留。相同表面共享图层与材质，独立外观用明确primitive组或源组件区分；不要求一部件一文件或一套网络，也不预建用不到的通道。
已有有效材质、用户指定方法和教程来源优先，局部修改不迁移整套材质。已有工程接入预览前，沿[既有材质与预览赋值](references/sop-preview-and-uv.md#既有材质与预览赋值)核对真实消费者。正式渲染按需联用Solaris/Karma；普通SOP预览不要求建立/stage或/mat。

## 决策顺序

1. **观察目标**：读取用户参考和当前模型。在实际能看清的范围内区分结构、表面图案、微表面和光照；保留未知。参考图任务先读[参考分析与来源选择](references/appearance-and-sources.md)；已有工程优化按其中的[表面表示审查](references/appearance-and-sources.md#已有场景的表面表示审查)从最终输出找当前差距；沿用先前成果时，按[跨场景基准](references/appearance-and-sources.md#跨场景的风格与质量基准)确定当前任务要延续的性质。
2. **确定细化程度**：按最终观察距离、用户的表示偏好与后续编辑需求，为相关部件选择下表中的程度。按当前画面贡献安排主要表面信息与微表面；做出一类纹理不代表其他图案已覆盖。复杂任务在现有任务笔记中简记“部位／可见特征／表示与来源／坐标与尺度／要改的量”；不是新账本或执行前置门。
3. **安排坐标**：需要空间变化时，在大量复制、形变或纹理细化之前确定UV分区、方向及尺度规则，读[SOP应用与UV](references/sop-preview-and-uv.md)。Boolean或倒角前后按原表面与新增面选择映射位置；纯色跳过坐标制作。
4. **构建与观察**：先在代表性源上用可辨方向图案打通实际表面，检查端面/侧面、尺度和接缝，再扩大到重复或装配。纯色COP与接入步骤见SOP应用资料；需要制作／加工图案时加载houdini-cop-workflow及其设计资料。已有图片可直接引用或接到稳定COP输出；需要生图素材时读[生成贴图与混合使用](references/generated-textures.md)，沿现有image_models/image_generate路线制作。
5. **修改与交付**：检查最终SOP、用户视窗和受影响控制状态。表面交给另一个模块处理时，交清承载面、坐标、图层角色与真实消费端，集成后回到最终输出核对覆盖。常用新增外观操作融入资产已有主控制，复杂实现留在模块中，按[总控与模块控制](../houdini-parameter-ui/references/control-bindings.md#总控与模块控制)建立明确来源。COP及消费节点的上层分组、导航沿network-handoff同步更新。保存实际材质网络与必需文件，保留能换图、改尺度和调表面的入口；文件路径遵循project_layout。不把图片生成成功或图层统计通过当作外观通过。

## 外观程度与表示

| 需求 | 表面表示 | 保留的判断 |
|---|---|---|
| 均匀表面 | 小尺寸纯色图层；粗糙度、金属度等用所需常量 | 已表达完整时停止，不为统一入口烘文件或增加空间细节 |
| 屏幕、印刷、标识、贴花与涂装 | 优先贴图或程序图层的底色／遮罩；按需增加发光、粗糙度 | 位置、方向、文字与图案比例；屏幕内容与玻璃响应分别处理 |
| 颗粒、划痕、织纹等微表面 | 按需增加粗糙度、凹凸／法线 | 观察距离、纹理尺度和高光响应；不是把颜色转灰就得到真实高度 |
| 需要真实表面起伏 | 按尺度选择位移或几何 | 位移的细分、强度、接缝与包络；法线不提供真实轮廓或接触 |
| 轮廓、接合、真实孔槽或交互结构 | 保留必要几何 | 表面图案不能替代要求的实体关系 |

不强制凑齐PBR通道，不以纹理复杂度评分。干净、风格化或低细节设计不默认增加污渍、磨损和噪声。
部件身份用组、name或明确类别维护；Cd可作调试／有意调色，不能从显示RGB阈值反推材料或删面。

空间图案明确承载表面、坐标与绑定，按需保留换图、位置、尺度和强度入口；独立贴花可以有局部坐标，相关通道从同一结构派生。几何贴花仍适合需要厚度或翘边的部分，并应跟随实际承载面。数量和密度按实际单位或模型比例控制，以整体和代表性近景判断可见贡献；需要比较表示方法时先试一小块，再扩大范围。

## 观察与范围

- 核对目标SOP上的实际材质赋值、UV两维、图案方向与预期尺度；用非对称图案区分翻转、错轴和常量采样。
- `render_view(显式SOP)`用于目标观察，`viewport_screenshot`用于用户视窗；两者观察条件不同。材质／纹理显示、Cd相乘、法线与光照分别定位，不能把调试色当贴图成功。
- 参数变化时复查图案附着和尺度；复制／形变后检查对应关系，不只检查点面数。修改当前疑点后更新相应观察，无固定重试轮数。
- 图层数据、材质显示、审美符合和重开分别报告；未成功识图写“视觉未验证”。SOP预览通过不证明Karma或其他渲染器通过。
