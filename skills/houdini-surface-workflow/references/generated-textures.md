# 生成贴图与混合使用

适用：复杂装饰、插画、自然材质外观或用户指定的生图贴图。来源选择与服务路由见[参考分析](appearance-and-sources.md)，坐标与SOP消费见[SOP应用](sop-preview-and-uv.md)。这里只补充生成素材的制作判断。

## 先确定图片的职责

| 角色 | 适合说明的信息 | 消费方式 |
|---|---|---|
| 重复材质底色 | 覆盖的实际尺度、方向、大小结构比例、需要连续的边 | 按声明的物理周期平铺；不是产品效果图 |
| 独有插画／印刷 | 构图、留白、有效图案区域、目标长宽比 | 用独立图案坐标定位，尺寸与位置可以独立于主体 |
| 透明贴花 | 主体与透明区域、边缘、颜色和alpha用途 | 保留alpha；颜色覆盖与使承载几何透明是不同操作 |
| 遮罩或其他数据 | 数值含义、内外区域、精确边界要求 | 生成结果先核对；确定性几何/文字/计量数据更适合可控生成 |

图片像素数决定可用采样，不自行携带毫米尺度、UV或材质物理参数。把“这张图覆盖多大范围”留在消费网络的控制中；以后换图时仍可继续调整。

## 提示词的组织

用任务需要的字段组织一段清楚的描述，无需凑齐字段或固定模板：

1. **图像用途**：底色、独有印刷、贴花等；说明要的是平面素材。
2. **主要结构**：单元、层次、疏密、方向、配色，以及必须保留的参考特征。
3. **覆盖与边界**：长宽比、图案占比、留白；仅在需要时声明U/V重复或透明背景。
4. **成像要求**：底色尽量均匀照明、正交、无定向高光和投影阴影；数据图说明其数值含义。
5. **精确约束**：确切文字、颜色或位置要求及允许的变化。重要字符用可控字体/栅格化制作，不依赖生图猜测。

例如，装饰陶瓷可描述“平面底色素材、不规则大小碎片和细颗粒的比例、有限配色、代表20cm区域、水平/垂直重复”；环绕标签可描述“展开的横向插画、指定留白与首尾边界、无产品和透视”。这些是表达方式，不是固定题材或材质配方。

参考像素使用references的本地文件，并说明其作用是内容、风格还是局部材质。用户只给产品照片时，不要求生图复制照片的灯光、曲面透视或遮挡。调用使用purpose='texture'；透明需求选择实际支持alpha的输出。

## 从文件到可编辑表面

保留返回的原图，按用途检查内容、实际尺寸、alpha、光照残留与所需边界。可直接使用时接入File COP或材质文件输入；需要调色、裁切、遮罩或多层混合时用COP加工，保持稳定输出。承载表面及通道共用明确坐标，尽量把图案位置/尺度的控制与图像内容分开。

| 当前缺陷或后续需要 | 可选择的处理 |
|---|---|
| 整体色调、明暗、饱和度调整 | 末端调色，保留原图 |
| 将图案限制在某块表面或印刷区域 | 独立mask与颜色混合；不必将图案轮廓变成大量实体面 |
| 重复边界可见 | 观察多次铺贴或半周期偏移后的边界，选择修接缝、局部混合或重新生成；Wrap本身不修接缝 |
| 只有局部内容不合适 | 在已知参考/编辑能力支持下定向修改，保留其他内容；先检查结果再决定重做 |
| 后续需要精确结构变化 | 用COP结构mask承担该变化，图片负责难以程序描述的外观部分 |

复杂素材可以采用“生成图片提供底色/插画，COP提供确定性遮罩、区域粗糙度和可控细节”的混合方式。颜色图不自动具有正确的高度、粗糙度或法线；不同通道须依据同一结构与材质含义构造，不能分别生成互不对齐的多张“同类材质”，也不能把照片亮度直接当真实深度。

平铺声明、alpha和无光照提示都只是生成目标。观察实际承载表面、接缝和最终距离下的细节，再报告已验证范围；不以文件存在或图片好看代替材质应用。与工程一同保存原图、必要加工网络和实际依赖路径，确认重开消费。
