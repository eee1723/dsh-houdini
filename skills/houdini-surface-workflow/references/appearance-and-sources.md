# 参考分析与来源选择

适用：参考图建模、外观复现、跨场景延续风格与细节标准、选择或生成纹理素材。结论用于当前资产，不把单一案例配方写成通用流程。

## 从图像到可编辑表示

先观察原图及相关部位，按可见证据分解以下问题；无需为每个像素建表。

| 观察对象 | 转成的设计决定 |
|---|---|
| 剪影、遮挡、接合和可见侧面 | 哪些特征必须保留几何；黑线可能是缝、阴影或印刷，不能仅凭颜色定性 |
| 表面分区、文字／图案、透明覆盖 | 独立表面组、底色或遮罩；准确位置、方向和边缘 |
| 高光宽度、粗糙变化、纹理方向和频率 | 材质参数与必要的细节通道；单张照片不能唯一确定粗糙度、深度或光照 |
| 透视、反射、阴影、景深与压缩 | 区分物体固有外观和成像效果，避免把它们全部画进底色 |
| 图案与部件尺寸的关系 | 固定物理尺寸、按面比例或可控重复；哪个变化应跟随模型参数 |

先匹配主要分区、图案尺度和方向，再处理局部破损与微细节。模糊／遮挡区域保留假设，必要时补参考，不把生图补出的细节当成原图事实。
对比使用相近观察距离和说明的光照条件；单纯提高整体相似度可能把阴影或结构误画进贴图。
用户尺寸和编辑意图约束参考解读；生成参考用于探索外观，不提供改变这些要求的依据。存在实质歧义时先说明尺寸/测量口径，不能仅凭效果图反推用户未指定的工程事实。

## 跨场景的风格与质量基准

区分用户指定的质量／风格基准与可复用的草稿、旧变体或构建源码。复用基础可以减少建造成本，其当前效果不自动替代用户指定的比较来源；同目录发现的成果或最新保存版也不自动成为质量标准。

读取基准对应版本的实际图片，按当前要判断的特征选择能看清它的整体或局部视图；需要理解构造或继续编辑时，再查相关源组件、材质和控制。先前作者的总结帮助定位资料，图像内容仍由负责该性质的作者实际观察。只继承用户要求参考的性质，基准中的已知缺陷、遮挡和未验证区域保留其范围。

把“同样风格、同样细节”转成当前任务可判断的设计目标，以下角度按需取用，简记在已有计划或任务材料中即可：

| 要交清的内容 | 在新任务中的用法 |
|---|---|
| 可迁移的形体与表面语言 | 主要比例、硬软边关系、材质分区、色彩与粗糙响应、细节的层级和分布；指出原图中对应部位 |
| 当前对象的内容与用途 | 按新对象的结构、实际尺度和编辑需求重新构造；源场景的具体零件、构图或数量只在要求沿用时迁移 |
| 判断所需的观察尺度 | 说明输出分辨率和部位在画面中的大小；整体层次可见不代表近景的接合、图案或微表面已可判断，按疑点补看已有局部图或取得针对性观察。材质比较核对光照、曝光和色管，区分表面性质与成像效果 |
| 必要示例与仍未知的部分 | 每张图说明用来判断哪项特征；疑点是接合、微表面或背面时补对应视图，不靠增加同类总览推断 |

跨类别延续的是相近观察尺度下可读的结构层次、材质区别和做工表达。例如涂层与裸金属的区别可以沿用，紧固件的数量和位置由新对象用途决定。细节标准不等于相同节点数、面数、污渍密度或贴图尺寸；清洁表面也能有清楚的结构与材质层次。

迁移方式尚不明确时，可从最能检验目标的局部或组件开始，在实际新对象上与基准比较，用结果决定表示、尺度与编辑入口是否适合扩大。已有明确结果时直接继续。对比既看目标特征是否保留，也看源对象的内容或成像效果是否被误带入。生成、深化和迁移可以是工作节奏，影响整体返工的构造或表面问题应在当前局部及时处理。

需要交给另一个任务时，沿[文件交付](../../houdini-network-handoff/references/file-delivery.md#作为后续任务的基准)保存可定位的版本、图片和稳定说明。图片数量、提示词长度和源工程存在都不证明接收者已理解标准；当前作者应能指出参考特征如何对应新输出，无法观察的性质继续保持未验证。

## 选择来源

| 来源 | 适用条件 | 主要成本与限制 |
|---|---|---|
| 已有文件／用户素材 | 已满足位置、精度、风格或品牌要求 | 先检查内容、分辨率、通道与使用范围，保持原文件 |
| COP程序图层 | 规律可描述，需重复、精确遮罩、调参、确定性变化或多通道关联 | 保留关键结构与尺度参数；不为一次简单颜色修改建大图 |
| image_generate | 不规则装饰、绘画、复杂图案或风格素材更容易用图像表达 | 外观与平铺不保证正确；后续结构性修改可能需重新生成 |
| 生成图片＋COP | 素材已合适，但需裁切、校正、遮罩、平铺处理或混合 | 保留原图与加工网络；已经可直接使用时省去加工 |

按用户偏好与首次制作、检查、以后修改的总成本选择。确定性文字／编号／刻度用字体、图形或可控栅格化；不要依赖生图猜正确字符。

## 生图入口

沿用户已选或已配置的生图路线，先用image_models发现准确provider/model。多个未定路线影响费用或质量且现有偏好不足时再询问；不把聊天模型名当成已验证的图片协议。
image_generate使用purpose='texture'与返回的实际文件；参考约束需传references的本地文件，提示词中的URL不会上传像素。不另读密钥、不写旁路API脚本、不自动换供应商或重复不确定请求。

选定生成素材路线后读取[生成贴图与混合使用](generated-textures.md)，按角色组织提示词、检查平铺与通道，再接入材质。离线素材任务不强制创建模型。

## 依据与适用边界

- [Adobe Image to Material](https://experienceleague.adobe.com/en/docs/substance-3d-sampler/using/filters/tools/image-to-material)与[Delight](https://experienceleague.adobe.com/en/docs/substance-3d-sampler/using/filters/tools/delight-ai-powered)：图像转材质涉及去光照和通道推断；本项目不因此依赖Sampler或宣称自动物理恢复。
- [VLMaterial](https://arxiv.org/abs/2501.18623)：图像到可编辑材质图的研究，使用训练与优化，不证明通用LLM仅靠提示词就能复现。这里采用的是“可编辑表示＋实际输出比对”的设计判断，不引入其训练、数据集或自动优化系统。
- [StyleAligned](https://arxiv.org/abs/2312.02133)：跨内容风格一致性使用特定扩散注意力机制。这里借鉴区分内容与风格的判断，不引入该机制，也不据此承诺通用Agent通过文字或参考图就能稳定迁移。
