# 模块设计与尺寸

## 粒度与自由度

求解状态表达受约束的离散选择，例如占用与接口状态、方向或样本模式。装配单元是一同定位的几何。公开源件对应用户希望独立编辑或替换的对象。一个状态可以装配多件，也可以和其他状态共用同一原型。套件的分件清单和组合过程中的中间几何不会自动成为状态；按其是否影响求解条件选择粒度。

先列出任务实际需要变化和保持的关系，再确定位置变量及模块边界。选择能保留这些差异的最粗表示。固定范围内可以使用格、边、顶点、表面或不规则图。范围边界与已经确定的成品轮廓分别表达。要让换种子改变轮廓，候选中须有可变占用及相应的结束、转接和边界处理能力。

先按 [SOP 完整源与布局](../../houdini-sop-workflow/references/modeling-methods.md#完整源组件与布局)定义实际接口、试装并发布校准后的源。生成或导入的套件读 [参考与接口适配](../../houdini-asset-integration/references/source-adaptation.md)。将实际影响候选的规格、占用与端口复用到模块定义里。几何端口表达实际接合关系，SOP 公共出口发布可消费的数据，两者可分别有多个。

## 模块记录

只记录实际消费者需要的数据，字段可以映射到几何属性、参数或外部模块定义。

| 数据 | 要解决的问题 |
|---|---|
| 稳定原型 ID、状态 ID、源出口 | 找到实际几何，区分原型与旋转等状态 |
| 单位、局部原点、轴向、离散规格 | 确定安装坐标与尺寸来源 |
| 占用单元或包络、净空、允许接触区 | 区分空间占用、功能空间与设计内搭接 |
| 允许的旋转和镜像 | 保持接口朝向、手性及功能含义 |
| 端口类型、局部位置或边界曲线、朝向、截面等配对量 | 让规则编译与实际拼接共用接口事实 |

根据任务为通行、支撑、表面连续、流向等关系赋予各自语义。同一面可以有多个端口。一个外表相邻关系也可以没有任何可通行端口。名义格宽、实际外包和可用净空分别保存，选择相应量参与检查。

## 规格与安装

从有效接口与占用确定格网和离散尺寸系列。图册只移动展示副本。尺寸、固定件变换、重复节距及接头归属沿用 SOP 方法。装配可按已解结果使用合法的中段、终止与过渡；会决定上游放置可行性的规格与接头可用性，参与对应层的约束。

旋转状态由同一变换作用于占用、端口和几何，去重依据旋转后的语义与占用。左右件或不同流向件可以共用形状，但保留有意义的状态区别。若将视觉变体纳入求解状态，明确结构类别的总权重，避免新增款式意外改变布局分布。

多格模块用一个放置决定占用全部单元，或用必须共同出现的内部状态表达。核对原点、每格占用、旋转后范围与外部接口，排除截断和重复放置。共享边、顶点或面上的实体按拓扑身份与角色确定唯一归属，组装后检查重复件与漏件。

## 何时改变状态

沿用接口的细节变体可由装配选择。跨件变化也可由共同装配层一次处理，只要结果仍符合求解所依赖的约束。影响占用、外部连接、支承、通行或其他硬条件时，把变化纳入相应状态或反馈重选。用可用端口和接头说明生成范围。增加同类型中段可扩展长度，分叉或规格转换需要相应的连接能力。逻辑试拼与实际几何通过分别判断。
