# 求解与生成质量

## 选择求解范围

每个位置是一个变量，候选域列出它可取的状态。传播删去在相邻域中已没有兼容取值的候选，选择再使一个未决域缩到一个状态。一个完整解满足全部指定硬约束。带权最少熵和最少剩余候选数是不同的位置选择启发式，候选等权时两者排序一致。

实现小样可展示一次选择如何排除邻位状态，以及剩下的候选如何影响后续放置。整案采样后过滤、从规则展开的语法生成和解后细节选择都有各自用途；若与 WFC 混合，沿最终输出指出哪些决定来自候选传播，哪些由其他阶段完成。

让需要探索的结构进入变量与候选。先画出固定输入、可变输入及其影响的输出关系，检查用户要求的连接方式、占用或形态是否仍可改变。大量候选可能共享相同的结构，多个手写布局之间选种子也可能限制输出范围。用真实结构差异判断表达是否充分。

分层适合存在明确依赖的情况。上层传递边界、可用规格和锁定，下层反馈缺少连接件、非法跨度或占用冲突等可定位原因。先重选受影响的决定，必要时回到上层。固定旧区域后局部重求须保留边界兼容并复核全局条件，失败可扩大未锁定范围或报告冲突。

若全局约束占主导，比较现有 WFC 扩展、图搜索与约束求解器，按规模、可解释性和依赖成本选择。方法来源与适用范围见 [研究依据](research.md)。

## 传播与搜索

1. 将范围、边界、模块、用户锁定和显式空位编译成域。空位只有符合领域意义时才作为候选，边界也可以由外部条件表达。应用初始约束并传播。
2. 按稳定位置和状态顺序选择未决位置，用指定种子和权重选择状态。使用局部变化队列更新受影响的域，按实测需要采用位集或兼容支持计数。
3. 发现空域或可靠的全局失败时，回退到相关决策并恢复受影响的域、传播状态和计数，或在声明的预算内重启。完整状态仍运行全局硬约束检查。
4. 解通过后生成安装数据，装配并检查实际几何。可靠的失败条件反馈到负责该选择的层，保留失败输入和涉及的实例、规则。

初始实现可以使用清楚的队列传播和回溯。优化依据求解规模、失败分布和耗时，不按语言预判性能。局部修改、分块和缓存有额外边界条件，采用前验证边界及失效规则。

固定随机实现、候选顺序及输入身份以便重现。结构与外观需要独立控制时使用独立随机流，记录种子、模块与规则版本、求解参数及实际预算。取消、限时和预算耗尽由实际执行路径检查并返回，不将一个长循环包装成无响应的交互按钮。

## 结果与失败

| 状态 | 应提供的事实 |
|---|---|
| 输入无效 | 错误定义、缺失源、非法锁定或不可解析的依赖 |
| 搜索分支矛盾 | 相关位置、规则、排除原因及实际重试情况 |
| 已证明无解 | 可靠传播对初始硬条件证伪，或完备搜索证明不可行 |
| 预算耗尽或取消 | 已消耗的时间与搜索量、代表冲突，可行性仍未知 |
| 逻辑解有效、装配失败 | 通过的阶段及实际几何失败位置 |
| 成品通过当前检查 | 可重跑的输入、解和已验证的几何与外观范围 |

失败输出保留诊断。若保留上次成功结果用于查看，显示其对应输入与过期状态，避免下游误当作当前解。修复失败时检查接口覆盖、边界、锁定和表示能力，再判断加强传播、改变搜索或修订模块。硬要求的变化需符合用户意图并明确说明。

## 多样性与性能证据

- 固定输入、模块、规则和预算，跑事先确定的一组种子，保留全部成功与失败。独立复跑代表输入，按能力补充边界、方向或锁定变化。集合大小和门槛取决于任务及成本。
- 按目标分别比较组织关系、尺寸和局部位置。例如连接图说明分支怎样改变，占用轮廓和面积说明体量怎样改变。再用同条件视图确认差异可辨，写明哪些骨架保持固定。按任务排除无关的整体平移、旋转、镜像或外观差异。哈希用于重现核对。
- 若差异不足，依次查看可变域、候选的实际结构、规则限制和权重分布，确认哪些决定已经被上游固定。明确上游规划与局部 WFC 各自贡献，再调整相应层。
- 分开统计求解成功和成品成功，记录决策、回溯、耗时与失败原因。查看典型耗时及慢种子，避免仅凭平均值判断交互体验。Houdini 中的装配、诊断和绘制开销按 [性能工作流](houdini-workflow.md#重算与交互响应)检查。

任务推进使用同条件结果检验每次模块、规则或求解修改是否解决了问题。小样通过后继续扩到所需能力。复杂度增加时优先保留可复现输入与清楚的失败位置，避免同时改变多个条件而失去原因。
