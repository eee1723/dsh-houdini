# 规则设计与观察

## 从可编辑定义编译规则

模块属性和用户规则各自保留一个维护源。参数、multiparm、几何属性或已有工程的数据表均可采用。求解可用派生的占用与邻接表，装配可用适配后的原型，观察可用图册或简化表示；各阶段追溯到同一份实际接口定义。核对公开的规格或端口字段确实被相应消费者读取。

显式模块可先依据端口类型、相对位置、朝向、截面及连接语义生成允许组合，再用明确配对条件表达类型标签无法区分的情况。声明缺省允许或禁止、例外的作用和优先级。局部例外仍须符合尺寸、占用等硬条件，需要特殊过渡时将其几何与规则一并表达。

overlapping WFC 的局部兼容从样本模式的重叠一致性导出，样本或提取参数修改后重新编译。明确模式锚点、模式内偏移和输出位置的映射，以及周期或非周期边界。锁定一个输出位置时，筛选所有覆盖该位置的有效模式候选，使对应偏移都满足固定值。重建最终输出时按重叠一致性恢复各位置取值，再按需要映射到资产，避免重复装配整块重叠模式。

规则编译考虑实际方向和状态变换。空间邻接边的反向表应表达同一对放置的逆向检查，同时保留单向流动等功能语义。旋转端口与旋转几何使用同一变换。检查未知 ID、不可用状态、边界终止、旋转遗漏和多格内部约束，在有问题的定义处给出原因。

编译结果带回模块、状态、端口及用户规则 ID。缓存身份覆盖会改变兼容性的输入，包含模块规格与端口、允许变换、样本、例外及编译参数。只修改外观时，接口合同未变的邻接数据可以复用。更改几何导致包络或接口变化时须重新核对。

## 约束的表达层

| 关系 | 表达与检查 |
|---|---|
| 相邻两位置能否同时取某组状态 | 方向性邻接、接口对齐、局部排斥和占用 |
| 整体数量、连通、顺序、承托等要求 | 与任务相符的图或全局约束，能提前证伪的部分参与搜索 |
| 成形后的接缝、覆盖、净空、碰撞 | 装配消费者上的几何检查，可靠的失败模式可反馈到前置规则 |
| 密度、节奏、偏好某类状态 | 权重或选择排序，用户明确要求的条件设为硬约束 |

局部兼容保证传播依据，完整解仍需通过所有指定的硬约束。分别定义不同关系的图。例如几何相邻、可达和支承可以有不同的边，多条接缝都匹配仍可能形成互不连通的组件。需要锚点或边界支承时显式声明。

## 给用户可理解的观察方式

规则区默认提供能直接检验当前规则的轻量试拼和候选观察。根据任务选择视口几何、颜色、标签、Geometry Spreadsheet 与参数面板，详细列表按选择显示。

| 观察入口 | 从实际数据生成的内容 |
|---|---|
| 选择模块与方向 | 当前允许和禁止的邻居，端口类型、规格和配对原因 |
| 选择一对状态试拼 | 按真实安装变换摆放源件，显示接触边、方向、净空及失败部位 |
| 选择目标位置或锁定 | 候选数、剩余状态、锁定来源与最近排除原因 |
| 查看求解冲突 | 空候选域、受影响位置和规则，能查回相关源与输入 |

用颜色配合文字或标记区分允许、禁止、未检查和冲突。区分范围外、已解为空、已解为模块、未决和空候选域，锁定或传播成单值等来源另行记录。可视化读取编译后的实际规则与求解状态，观察用位移不参与规则计算。全局条件未验证时保留该状态，单对试拼通过只表达已检查的局部关系。

大状态集只展示所选模块、方向或位置的子集。传播观察可以提供按需单步或有限事件记录，常规生成关闭逐步几何重建。重放已有求解记录时显示其输入身份。局部排除链用于解释这次冲突，只有专门算法证实时才称为最小冲突集。

## 验证规则确实生效

对要求由模块接口驱动的生成器，选一对可复现的相邻状态，从真实入口改一侧接口描述或配对规则。固定范围和锁定，观察具体兼容边与候选的增删，再确认求解绕开该组合或报告相应冲突。需要时固定一侧状态以暴露传播。恢复后复跑原输入。类别开关、权重修改和同接口换源各自验证对应能力。同种子改规则也可能改变随机流或取样顺序，用兼容边和候选变化判定规则是否生效。

另外按本次能力选择反例，例如旋转件的朝向错误、局部都匹配却整体断开、同包围盒却封堵了开口、跨格件被边界截断，或输出格锁定与覆盖它的模式冲突。检查必须经过真实消费路径。对定义自身重复运算只能验证数据一致性，实际源替换、实体关系和最终输出另用对应检查覆盖。
