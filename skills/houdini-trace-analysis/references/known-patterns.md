# 通用诊断线索

这些线索用于找证据，不是执行政策、节点选择规则或完成门。历史修复状态由 Git 与现役合同维护，审计不据旧案例新增审批或限制。

| 线索 | 要核对的事实 | 适用边界 |
|---|---|---|
| 服务端可用而页面缺失 | root loader 的 client modules 与 preset 内工具是否分别交付 | preset 注册不能替代浏览器模块加载 |
| 工作区与 HIP 错位 | 请求目录、已确认 workspace/session cwd、现场HIP、产物/通用shell目录 | HIP位置和工作区可以有意不同，需任务背景 |
| 一条请求多个运行身份 | runtime_id 生成、重启代际、执行对象和请求表的创建时机 | session/author ID本来就不等于runtime |
| 返回摘要吞事实 | 原始canonical、result_ref、直接role=tool与历史嵌套格式、PTC子调用 | 摘要省略不能当作没有执行或没有图片 |
| 能力存在却反复猜错 | 当时help是否有输入/返回合同，小例子与相对节点引用是否一致 | 模型已读完整合同后误用仍可能是模型错误 |
| 错误阶段混用 | 查询/预检/派发/首次写入/回滚的实际事实 | caught查询错误不等于修改事务失败 |
| 假绿的几何证明 | 实际最终实体与driver/proxy、拓扑、坐标、阈值、计数及总判定一致性 | 单纯需要driver或调试代理时它可以是合法产物 |
| 图像成功被升级为完成 | 图片访问与附件、原图版本/目标、描述内容、最终声称 | 像素、bbox和模型描述均不自动证明语义 |
| 查回/压缩膨胀调用 | callId重放与canonical runtime/sequence去重；poll和资源读取独立列出 | 缺canonical时独立执行数是未测而不是零 |
| 停顿被归为模型耗时 | call/result时间、provider usage、Houdini执行时长、终止原因 | 空档与字符量不能推出费用或浪费 |
| 审计抽错新格式 | v4发现、native surface、runtime-context、tool直接文本与nested PTC | 旧格式仍可读；无效行/不匹配结果须显式说明 |

必要领域知识按任务加载；动画、HDA、资料解析与几何关系采用实际目标的观察方法。工具合并、能力封装和信息裁剪需说明具体责任与收益，案例数量不替代设计论证。
