# 故障报告与本地诊断包

## 用户入口

会话标题栏的「报告问题」收集该会话的诊断证据，不启动模型、不执行HOM、不恢复或重启工程。填写问题后直接点击「保存报告」，程序会自动整理并发起浏览器下载，无需先生成预览；以浏览器或原生下载窗口的完成状态为准。也可先选择「查看报告内容」，按中文名称查看各项记录。关闭、切换会话、Host重连和修改选项都会使旧内容失效，下次保存自动重新收集。

Version & Updates窗口提供独立的「报告问题 / 导出诊断包」。该入口由bootstrap携带，工作区或Node未启动时也可收集已有运行记录；不读取其他会话，不把缺少会话证据当成没有发生故障。启动管理器尚未加载运行包时，安装根下的最近运行记录仅作历史证据。

两种入口使用同一个[收集器](../houdini/python3.11libs/dsh_support_report.py)。先在本机生成ZIP，查看内容为可选步骤；打开GitHub页面不上传或提交任何报告。用户分享前检查文字和文件，在[问题模板](../.github/ISSUE_TEMPLATE/bug_report.yml)中粘贴摘要并附加ZIP，也可通过私下渠道交给开发者。

网页复用DSH的Modal、Button和Checkbox，关闭/保存固定在弹窗头尾，仅中间内容滚动。Qt窗口保持同样的直接保存、可选详情和固定操作区。记录用中文说明展示；展开后原文件名与技术正文才出现，正文独立滚动，并始终提供「收起详情」。当前/之前运行情况与对话内容分别说明用途，原生窗口不提供无法收集的对话选项。

DSH原生「更多操作 → 下载 Session 日志」及`/export`仍按其完整会话合同导出正文、子会话和附件；这类完整包不等同默认诊断包，不自动脱敏。Houdini内嵌窗口通过[下载处理](../houdini/python3.11libs/dsh_downloads.py)接收原生下载及诊断包，提供保存位置、完成、取消与失败反馈；关闭活动下载窗口会取消该下载。

## 数据与边界

| 内容 | 来源与规则 |
|---|---|
| 会话 | Host只接受浏览器当前传入的精确session ID，沿DSH持久读取接口读取；不以最近修改文件猜会话，不启动冷会话Agent |
| 时间线 | 复用原生/嵌套工具回执适配，保留调用关系、状态、错误和工程接续事实；不建立第二份会话数据库 |
| 长历史 | 超过2064个事件时读取最初64个和最后2000个；中间缺失、字节上限、正文省略单独报告，不能宣称完整因果链 |
| 正文 | 默认排除；用户单独选择后只附加此次读取范围内的会话事件，仍不收集图片、附件、工程或凭据文件 |
| 运行日志 | 独立工作台读取当前Host、窗口日志和可选的上一运行目录；旧受管运行读取进程目录，旧源码内嵌入口使用`.dsh-web.log`。每份最多256KiB尾部，截断时跳过不完整首行并记录缺口 |
| 版本 | 区分磁盘package版本、Host已加载的预期合同、历史运行标记与历史执行事实；没有主动现场探测，不把历史标记称作live验证 |
| 缺失 | 日志缺失、损坏、路径链接、持久化失败、历史截断均如实报告；错误会话或无效读取身份拒绝，不替换成另一会话 |

正式安装默认根为`%LOCALAPPDATA%/DSH-Houdini`，可由安装选择改变。独立运行记录在`workbench/<运行实例>/`，窗口日志在`workbench/desktop.log`；源码运行根为`DSH_HOME/houdini-workbench`。旧受管日志仍在`runtime/<进程实例>/`，DSH数据仍在`data/<安装实例>/`。收集器不读取含工作台启动凭证的`desktop.json`。导出保存到用户选定位置，不清理会话、恢复点或旧安装；自动轮换与远端保留策略不属于当前实现。

收集、压缩和文本处理在worker/子进程进行，不在GUI线程探测网络或运行进程。Host收集器使用启动环境中的Houdini Python，不借助故障会话的目标绑定。原生窗口使用纯Python标准库，不依赖Host、Bridge或模型。新的bootstrap功能须由完整安装器交付，运行包更新本身不证明管理器已经更新。

## 脱敏与分享

默认只投影诊断所需字段；通用聊天正文、工具参数和业务结果不进入默认时间线。运行日志、错误和用户描述仍可能含业务内容，所有导出文件都可在保存前预览。

收集器隐藏常见密钥字段、Authorization/Cookie、登录URL、常见访问令牌、私钥文本、邮箱及常见绝对路径。同一路径在一个报告内用相同替代标记关联。`frontend.log`可能含工作区登录令牌，禁止绕过收集器原样公开。脱敏是尽力处理，不能保证识别任意自然语言、代码或未知编码中的秘密；完整正文建议私下分享，用户仍须检查。

ZIP只包含预览中的同一份处理后文本，不暗带原始文件。`manifest.json`声明版本、报告编号、选中会话、缺口、脱敏计数和各文件的字节数/SHA-256。摘要用于说明与复现，不由模型生成，不作为执行事实。哈希只检查文件一致性，不证明报告来源可信。

GitHub用于问题跟踪及用户手动附加已检查的ZIP；公开Issue和附件公开可见。当前没有自动上传、内置GitHub凭据或后台遥测收集。后续私有上传必须保持同一导出合同、用户明确发送与单独访问控制，不能在私有上传失败时回退公开发布。

## 开发者检查与验证

使用`python tools/inspect-support-report.py <诊断包.zip> --html <报告.html>`检查包内清单和哈希，并生成离线可读页面。读取器不解压、不执行内容、不联网；拒绝未知/重复条目、路径穿越、清单不符及超过8MiB展开大小的包，HTML中的文本全部转义。用户日志始终作为不可信数据，不作为Agent指令。

完整DSH会话trace分析仍按[开发维护](development.md)及houdini-trace-analysis skill执行，诊断包中的受限时间线不能冒充完整会话重放。

验证入口：

- [Host定向回归](../tools/tests/support-report.test.mjs)：精确会话、真实消息结构、原生/嵌套错误、正文选择、取消、损坏、关闭读取句柄与历史限额。
- [前端竞态](../tools/tests/support-report-client.test.mjs)：切换会话、Host重连、关闭与修改选项时使旧响应和预览失效；effect运行前也不能保存其他会话的报告。
- [收集器与不可信包](../tools/tests/dsh-support-report.test.py)：令牌/转义JSON/私钥、预览与ZIP一致、文件损坏/缺失、截断、篡改和超限包。
- [真实Qt检查](../tools/tests/run-support-qt.py)：`--hython <hython.exe>`可重复传入，隔离检查H21/H22下载完成、无效位置、取消和离线管理器报告。
- [真实DSH组合](../tools/tests/run-support-dsh.py)：`--hython <hython.exe> --runtime-cache <精确DSH缓存>`启动独立数据与认证Host，通过实际Qt所选会话验证诊断ZIP和原生完整导出，不调用模型或用户Bridge。

这些检查不证明用户已加载新版，也不替代正式签名包、完整安装器和用户原生菜单入口的交付验收。
